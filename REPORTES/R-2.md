## 2. Hallazgos que cambian la semilla

- **«Medio millón» es el Met, no los candidatos de la semilla.** El Met declara 492.000 imágenes de dominio público; el Smithsonian declara 3 millones. La cifra del vídeo encaja con el Met. Es **H1**, no SPEC: no vi el fotograma.
- **«800.000» no aparece como cifra oficial del Rijksmuseum.** Su página de datos dice «más de un millón de objetos». El encaje es por alta resolución + ukiyo-e + mariposas/pavo real. **H1**.
- **La API de NYPL ya no existe.** El Repo API se retiró el 1-ago-2026 y no hay reemplazo. Quedan los metadatos de dominio público en GitHub y la descarga imagen a imagen. Esto invalida cualquier plan que contara con esa API.
- **Cooper Hewitt no es «todo CC0».** El volcado JSON de metadatos es CC0, pero el propio README avisa que las imágenes no están incluidas ni cubiertas por esa licencia.
- **Solo Met y Rijksmuseum ofrecen API + descarga masiva sólidas.** NYPL está degradado; Letterform, SVA, Design Reviewed, Fonts In Use y PGDA son de consulta. `archives.design` es una capa de curación sobre Internet Archive, no un archivo con API propia.
- **La entrada 10 sigue abierta.** No se encontró con seguridad el libro japonés «マーク・シンボル». No se inventó URL ni licencia.
