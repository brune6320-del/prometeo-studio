## 2. Cómo funciona el ritual

1. Se pulsa **Volver a mirar**.
2. El sistema propone 3 referentes de todos los tableros:
   - el que lleva más tiempo sin mirarse (`vistoEn` más antiguo; nunca visto primero);
   - uno al azar con la semilla visible;
   - uno del tablero abierto.
3. Se eligen los ojos (o se deja el que salió con la semilla).
4. **Mirar** pide las lecturas al backend. Cada propuesta tiene su texto y su modelo.
5. **Aceptar** es el único gesto que cambia el referente: añade la lectura y actualiza `vistoEn` con la fecha del día. **Descartar** no guarda nada.
6. Sin clave o sin red, las 3 propuestas salen con el campo vacío y `modelo: manual`; se escriben a mano y se aceptan igual.

La selección es determinista para una misma semilla y un mismo conjunto de referentes: el orden de las tarjetas no altera el resultado porque se ordena por `boardId:cardId` antes de elegir.

## 3. Dónde poner la clave (y dónde no)

La clave va **solo en el entorno del proceso del backend**. El frontend nunca la ve.

**Backend de desarrollo** (Vite reenvía `/api` a `127.0.0.1:8000`):

```bash
cd ~/Projects/prometeo-luna-release
export DEEPSEEK_API_KEY='sk-...'
PYTHONPATH="$PWD:$PWD/fase0" \
  studio-desktop/resources/runtime/bin/python3 -m uvicorn studio.backend.app:app \
  --host 127.0.0.1 --port 8000
```

**App de escritorio**: el sidecar hereda el entorno del proceso que lanza la app, pero macOS **no** hereda el entorno del shell si se abre desde Finder. Para que el ritual tenga clave, lanza el binario desde la terminal:

```bash
cd ~/Projects/prometeo-luna-release
DEEPSEEK_API_KEY='sk-...' \
  "studio-desktop/src-tauri/target/release/bundle/macos/PROMETEO Studio.app/Contents/MacOS/prometeo-studio"
```

**No** se creó `studio/frontend/.env.local`. Si algún día se usara el camino directo desde el frontend, cualquier variable `VITE_*` queda embebida en el bundle y es legible por cualquiera que abra la app: sería un riesgo real, no una precaución teórica. El camino elegido (backend) evita ese riesgo. `.env.local` está ignorado por `studio/frontend/.gitignore` (`*.local`), pero eso solo evita el commit, no la exposición en el build.

- **Markdown por tarjeta**: se conectó el exportador de Referente al Markdown del tablero, pero no se añadió un botón «Markdown» dentro de la ficha. Sigue pendiente como gesto independiente.
