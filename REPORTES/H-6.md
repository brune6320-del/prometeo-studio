## 1. Qué se hizo

**Nuevo**

- `studio/frontend/src/board/publicar.ts`
  - `buildPublishPage(...)`: genera el HTML, el CSS y el JS de la vista elegida reutilizando la lectura pura ya existente (`buildArchive`, `buildMuro`, `buildMesaPieces`). No duplica reglas de autoría.
  - `collectPublishPieces(...)`: devuelve exactamente las piezas que la vista usa; una entrada por pieza y sin archivos huérfanos.
  - `publishFileName(...)` y `publishSlug(...)`: nombres estables, sin acentos ni símbolos, con prefijo numérico (`media/01-pareidolia.png`). Dos piezas con el mismo título no colisionan.
  - `fitImageSize(...)`: encaja dentro de 1.600 px conservando proporción.
  - `preparePublishAsset(...)`: imagen ≤1.600 px en memoria (canvas); si ya cabe, conserva los bytes originales. Vídeo, audio y archivos se copian tal cual.
  - `buildPublishZip(...)`: ZIP sin compresión de respaldo para navegadores sin selector de carpetas.
  - `sanitizePublishedHtml(...)`: elimina rutas `/Users/` y `/home/`, valores de `token`/`access_token`/`api_key` y cadenas `Bearer` del HTML final.
  - `publishFrameToDirectory(...)`: pide la carpeta antes de preparar las imágenes —para no perder el gesto del usuario— y escribe `index.html`, `style.css`, `app.js` y `media/`.
- `studio/frontend/src/tests/publicar.test.ts`: 6 tests nuevos.
- `index.html` publicado
  - **Archivo**: nota fija, reloj vivo, feed con carrusel, índice con anclas internas.
  - **Muro**: columnas de miniaturas con código y título, caja de luz.
  - **Mesa**: piezas giradas con la misma semilla (7) que la app y caja de luz.
  - **JS** (`app.js`): solo reloj, carrusel y caja de luz. 3.255 bytes.
  - **CSS** (`style.css`): 5.228 bytes, tipografía de sistema mono, sin fuentes ni recursos externos.

## 2. Comportamiento

- **Botón**: solo en marcos. Si la vista es Libre, pide elegir Archivo, Muro o Mesa de luz.
- **Carpeta**: se escribe directamente en la carpeta elegida, creando `media/` si no existe. Se sobrescriben `index.html`, `style.css`, `app.js` y los medios con el mismo nombre; el prefijo numérico evita colisiones internas.
- **Sin servidor**: todas las referencias son relativas (`style.css`, `app.js`, `media/…`). No hay rutas absolutas, `data:` incrustados ni peticiones de red.
- **Sin subida**: el módulo no lee la sesión, el host nativo ni el token; no hay `fetch`, `XMLHttpRequest` ni envío alguno.
- **Imágenes**: si superan 1.600 px por cualquier lado se reducen en canvas conservando proporción; PNG/WebP/GIF/SVG se guardan como PNG y JPEG como JPEG. Si ya caben, se copian sin recodificar.
- **Otras piezas**: vídeo, audio y archivos se copian íntegros a `media/`; el HTML los referencia igual.
- **Respaldo**: si `showDirectoryPicker` no existe (Safari, Firefox, WebView de Tauri), se descarga un ZIP con la misma estructura para descomprimir donde se quiera.
- **Redacción**: el HTML final sustituye `/Users/…` y `/home/…` por `[ruta local]` y los valores de token por `[oculto]`. Es deliberado: una ruta o un token pegados en una nota no salen del equipo.

## 4. Límites que quedan (dichos, no tapados)

- **Selector de carpeta**: depende de File System Access API. Funciona en Chrome, Edge y Brave. En Safari/Firefox y en el WebView de Tauri no existe: allí el botón descarga un ZIP. **La descarga del ZIP dentro de Tauri no está verificada**; si el host la bloquea, queda el navegador.
- **Carpeta elegida**: no se probó el diálogo real del sistema en esta sesión (E1 no puede elegir carpeta). La escritura usa la API estándar, pero la validación con las manos de Bruno sigue pendiente.
- **Publicación es una foto**: el sitio generado no se sincroniza con el tablero. Si se edita el marco después, hay que volver a publicar.
- **Solo vista activa**: publica Archivo, Muro o Mesa. No hay selector de las tres a la vez ni publicación del tablero completo.
- **Piezas**: el archivo por pieza se genera para medios. Notas, enlaces y etiquetas son texto del HTML, no archivos en `media/`.
- **Imágenes grandes**: GIF animado que exceda 1.600 px se convierte en PNG estático; el resto de GIF se copia tal cual. SVG que exceda el límite también se rasteriza.
- **Seguridad**: la redacción de rutas y tokens altera el texto visible si alguien escribió literalmente `/Users/…` o `token=…` en una nota. Se prefiere la privacidad a la fidelidad literal.
- **Peso**: el JS se mide en bytes UTF-8 (3.255), no en KB de disco del sistema.
- **Sin commit de H-6**: los archivos quedan en el árbol de trabajo tal como se pidió.

## 7. Lo que tienes que hacer tú

1. Abre la app en **Brave o Chrome** (no Safari) y entra en un tablero.
2. Dibuja o elige un marco con al menos una etiqueta, dos medios y una nota.
3. Cambia «Ver como» a **Archivo** y pulsa **Publicar**; elige una carpeta vacía.
4. Abre `index.html` con doble clic: comprueba reloj, carrusel e índice.
5. Repite con **Muro** (clic en miniatura, ← →, Esc) y **Mesa** (giro y caja de luz). Dime si algo se ve distinto a la app.
