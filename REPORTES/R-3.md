## 2. Cómo funciona la importación

- La semilla tiene 12 entradas: 5 de `media 11`, 6 de `media 13` y 1 de `media 5`.
- Se crean 3 marcos con esos títulos; `hijos` guarda los ids de sus fichas. Los marcos se pintan en vista Libre, detrás de las tarjetas.
- `verificar: true` añade la etiqueta **«por verificar»**. `url: null` se guarda como cadena vacía; una URL existente se conserva aunque `verificar` sea true.
- Reimportar no duplica: los ids son deterministas. Si Bruno movió una ficha, la posición se conserva; si pegó una imagen o escribió una lectura, también.
- El tablero se busca por título «Biblioteca» dentro del proyecto activo. Si no hay proyecto activo, se busca en todos los tableros.

## 4. Límites que quedan (dichos, no tapados)

- **Semilla duplicada**: `docs/STUDIO/referentes-semilla.json` sigue siendo el original, pero el frontend usa una copia tipada en `src/board/referentes/semilla.ts`. Si el JSON cambia, la copia no se actualiza sola. No se añadió script de sincronización para no tocar el flujo de documentos.
- **Pegado**: se acepta texto `http(s)`. No se leen archivos de imagen del portapapeles ni se descarga la imagen; la ficha muestra la URL remota. Si la URL no es una imagen real, el navegador mostrará el hueco roto.
- **«Sobre un Referente»**: se resuelve por puntero encima o por selección única. Si hay varias tarjetas seleccionadas, el pegado no adivina cuál.
- **Actualización**: la semilla manda en nombre, vídeo y URL no nula. Las posiciones y los datos de Bruno no se recolocan ni se borran. Las fichas que ya no estén en la semilla se conservan al final del tablero.
- **Marcos**: siguen en vista Libre. No se fuerza Muro/Mesa porque esas vistas solo pintan medios y ocultarían las fichas.
- **Ancho de marcos**: se subió el límite de normalización a 2400. Es un cambio de comportamiento al cargar, no de esquema; los marcos antiguos más anchos que 440 ahora conservan su ancho real.
- **Prueba real**: falta abrir la app Tauri/Brave y usar el botón con las manos. El build y los tests no demuestran el gesto de pegar en el WebView.
- **Evidencia**: E1 de unidad. Sin E2 (otra máquina), E3 (baseline) ni E4 (corpus externo).
