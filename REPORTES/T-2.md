# T-2 · Selección y borrado como en una herramienta profesional

Fecha: 25-oct-2026 · Rama: `studio/collage` · Sin push.

## Principio

Borrar es inmediato y se arregla con deshacer. El historial es la red de
seguridad; ningún diálogo `window.confirm` corta el gesto.

## Atajos finales

La tabla vive en `studio/frontend/src/board/atajos.ts` y es la única fuente de
verdad: el listener de `keydown` y el panel de ayuda `?` se generan desde ella.
Ningún atajo se dispara con el foco en `input`, `textarea`, `select` o
`[contenteditable="true"]`; Esc sí cierra diálogos aunque el foco esté dentro.

Detalles de implementación:

- Una ráfaga de flechas (≤ 500 ms entre pulsaciones) comparte clave de
  coalescencia y produce **un solo paso de historial**. Una pausa abre otro.
- `⌘/Ctrl + C` guarda una copia en `board/portapapeles.ts` y deja en el
  portapapeles del sistema solo una marca corta. Al pegar, una imagen o un
  texto externos tienen prioridad; si no hay nada externo, se pegan las
  tarjetas con ids nuevos y relaciones internas remapeadas. Pegar dos veces
  escalona la copia 24 px.
- `⌘/Ctrl + A` toma solo las tarjetas del documento activo (no las de tableros
  anidados) y omite las que ya se pintan dentro de un marco con vista propia.

## Confirmaciones eliminadas

Se quitaron los **4** `window.confirm` del tablero:

1. `removeCard`: «¿Eliminar esta tarjeta y sus relaciones?» / «¿Eliminar este marco?».
2. `deleteSelectedCards`: «¿Eliminar N tarjetas seleccionadas y sus relaciones?».
3. `removeCurrentBoard`: «¿Eliminar “…” y sus tarjetas?».
4. `handleDeletePdfReference`: «¿Eliminar la referencia a “…”, página N?».

En su lugar:

- Borrar tarjetas muestra abajo `N tarjetas eliminadas · Deshacer` durante
  **5 s**. El botón usa el mismo `undo()` que `⌘/Ctrl + Z`. Si había tarjetas
  bloqueadas, el aviso añade «· N bloqueada(s) se queda(n)»; si todas estaban
  bloqueadas, se avisa y no se borra nada.
- Eliminar un tablero o una referencia PDF también es inmediato y ofrece
  deshacer en el mismo aviso: restaura el tablero y su vínculo de proyecto, o
  vuelve a guardar la referencia.
- Borrar N tarjetas es **una sola entrada de historial**: se filtran las
  tarjetas una vez, se limpian las referencias de marcos/columnas en una pasada
  y se eliminan las relaciones afectadas. `⌘/Ctrl + Z` devuelve todas con sus
  posiciones, relaciones y pertenencia a marcos.

## Rendimiento

Medido con Playwright + Brave sobre **`vite build` + `vite preview`**
(`playwright.t2.config.ts`), tablero con 500 notas, `⌘+A` y `Supr`, tres
repeticiones:

| Medida | Resultado |
|---|---|
| Duración síncrona del borrado | **0,6 ms** |
| Primer fotograma tras borrar | **8,2 ms** |
| Fotograma máximo (3 pasadas) | **17,5 / 17,6 / 23,2 ms** (todas < 32 ms) |
| Tarjetas restantes | 0 |
| `⌘+Z` | devuelve las 500 |

Para llegar ahí se añadieron dos optimizaciones de LOD:

- Por debajo del 35 % de zoom, `BoardCardItem` pinta una pieza ligera (título,
  sin contenido, controles ni capa GPU por tarjeta). El CSS ya ocultaba el
  cuerpo; ahora tampoco se monta el DOM que no se ve.
- `contain: layout style paint` en el escenario y `contain: layout style` en
  tarjetas/marcos evita recalcular el lienzo entero al desmontar cientos de
  piezas.

En el servidor de desarrollo el mismo test mide ~27 ms de primer fotograma
(React en modo dev); el presupuesto de 32 ms se exige en la configuración de
producción.
